系统概述

xxybacktest 是一套量化策略从研发到每日自动运行的完整闭环。用户写一次策略代码，注册为模拟账户后，系统每天自动重跑回测、更新净值曲线、生成当日交易信号。打开 Web 界面就能看到"今天该买什么卖什么"，直接跟单操作。

核心功能

  • 策略回测：基于历史数据验证策略表现
  • 模拟账户：将策略注册为每日自动运行的模拟交易账户
  • 定时任务：灵活调度数据更新、策略重跑等任意脚本
  • Web 可视化：策略净值、持仓、信号一目了然

架构简图

xxy-sim 启动
└── Flask (port 5000)
    ├── /              ← 账户列表
    ├── /account/<id>  ← 账户详情（净值曲线、持仓、信号）
    ├── /tasks         ← 定时任务管理
    └── /docs          ← API 文档（本页）

APScheduler（后台）
    ├── builtin_run_simulation  ← 内置：每日模拟交易重跑
    ├── task_数据更新            ← 用户注册：数据更新脚本
    └── task_xxx                 ← 用户注册：任意脚本

回测用法

编写策略代码

策略由两个函数组成：initialize 和 handle_data。

from xxybacktest.simulation import submit

def initialize(context):
    """初始化函数，策略注册时执行一次"""
    # 加载历史数据、设置参数等
    pass

def handle_data(context):
    """每日调仓函数，每天收盘后执行一次"""
    # 选股、调仓等逻辑
    # 示例：全仓买入
    context.order_target_percent("000001.SZ", 1.0)

运行单次回测

from xxybacktest.backtest import run_backtest

context = run_backtest(
    initialize=initialize,
    handle_data=handle_data,
    start_date="2024-01-01",
    end_date="2024-12-31",
    capital=100000,          # 初始资金 10 万
    data_path="./data",      # xxydb 数据目录
    asset_type="stock",      # 'stock' 或 'fund'
    benchmark="000001.SH",   # 基准指数
    plot=True,               # 是否展示回测曲线
)
参数说明默认值
initialize初始化函数 callable(context)必填
handle_data策略主函数 callable(context)，如果为 None 需在 initialize 中自行注册 run_dailyNone
start_date回测起始日 'YYYY-MM-DD'必填
end_date回测结束日 'YYYY-MM-DD'必填
capital初始资金1000000
data_pathxxydb 数据目录./data
asset_type资产类型：'stock'（股票）或 'fund'（基金）stock
benchmark基准指数代码000001.SH
plot是否在 Notebook 中展示回测曲线和绩效指标True

策略编程接口

Context 对象核心属性

属性说明
context.current_dt当前日期时间（datetime 对象）
context.previous_date上一个交易日日期字符串 'YYYY-MM-DD'
context.portfolio.cash可用现金
context.portfolio.total_value总资产（现金 + 持仓市值）
context.portfolio.positions持仓字典 {code: Position}
context.trade.benchmark基准指数代码
context.trade.asset_type资产类型 'stock' / 'fund'
context.g用户全局变量字典（可存放策略状态）

下单函数

所有下单函数均已绑定到 context，在策略中直接通过 context.xxx() 调用。

函数说明
context.order(security, amount) 按数量下单。amount > 0 买入，amount < 0 卖出，0 不下单
context.order_buy(security, amount) 买入指定数量（股）
context.order_sell(security, amount) 卖出指定数量（股）
context.order_value(security, value) 按金额下单。value > 0 买入对应金额，value < 0 卖出对应金额
context.order_target_value(security, value) 调仓至目标市值。value=0 表示清仓
context.order_target_percent(security, percent) 按总资产百分比调仓。percent 为 0.0~1.0 小数，如 0.1 表示 10%
context.inout_cash(amount) 出入金。正数入金，负数出金

账户管理

from xxybacktest.simulation import (
    list_accounts, get_account,
    pause, resume, delete,
    run_single, run_all,
    get_account_nav, get_account_positions, get_account_orders,
)

# 列出所有账户
accounts = list_accounts(data_path="./data")

# 只列运行中账户
running = list_accounts(status='running', data_path="./data")

# 查看单个账户详情
info = get_account(account_id, data_path="./data")

# 暂停账户（暂停后不再参与每日重跑）

# 恢复账户

# 删除账户及其所有历史数据

result = run_single(account_id, end_date="2024-12-31", data_path="./data")

# 手动重跑所有运行中账户
results = run_all(end_date="2024-12-31", data_path="./data")

# 查询净值、持仓、订单
nav_df = get_account_nav(account_id, data_path="./data")
pos_df = get_account_positions(account_id, date="2024-12-31", data_path="./data")

定时任务

系统使用 APScheduler 管理定时任务，支持热注册、热删除，无需重启服务。

内置任务：每日模拟交易

启动 xxy-sim 时自动注册，通过 --time 参数控制触发时间：

xxy-sim --data ./data --time 22:00   # 每晚 22:00 自动重跑所有运行中账户
xxy-sim --data ./data --time 15:30   # 收盘后 15:30 执行

注册自定义定时任务

from xxybacktest.simulation import schedule_task

# 方式一：每天固定时间
tid = schedule_task(
    name="数据更新",
    script="./data_renew.py",   # 脚本的绝对或相对路径
    time="17:30",                # 每天 17:30 执行
    data_path="./data",
)

# 方式二：cron 表达式
tid = schedule_task(
    name="季报数据",
    script="./update_quarterly.py",
    cron="0 10 1 1,4,7,10 *",    # 每季度第一天 10:00
    data_path="./data",
)
参数说明
name任务名称（展示用）
scriptPython 脚本路径
time每天固定时间，格式 HH:MM，与 cron 二选一
cron标准 5 段 cron 表达式（分 时 日 月 周）
data_path数据目录路径
注意：time 和 cron 只能指定一个。相同 name + script + cron 的任务不会重复注册。

cron 表达式参考

需求cron 表达式
每天 22:000 22 * * *
每天 17:3030 17 * * *
工作日 9:000 9 * * 1-5
每周一 10:000 10 * * 1
每月 1 日 9:000 9 1 * *
每季度首日 10:000 10 1 1,4,7,10 *

Web 界面

账户列表页（/）

  • 展示所有模拟账户的累计收益率、当日收益、最大回撤
  • 点击账户卡片进入详情页
  • 支持策略组合：多选账户后按权重合成组合净值曲线

账户详情页（/account/<id>）

  • 净值走势：策略净值 + 基准指数 + 超额净值三条曲线
  • 计划交易：最新调仓信号（今天该买什么/卖什么）
  • 当前持仓：代码、名称、数量、成本、市值、占比、累计收益
  • 历史成交：带分页的完整交易记录
  • 操作按钮：暂停 / 恢复 / 删除账户

任务管理页（/tasks）

  • 查看所有定时任务的名称、cron 表达式、下次执行时间、上次状态
  • 手动触发：立即执行一次任务
  • 查看日志：弹出窗口实时展示任务执行日志（3 秒轮询刷新）
  • 删除任务：用户注册的任务可删除，内置任务不可删除

常见问题

Q：Flask 的 debug 模式可以开吗？

A：不可以。APScheduler 的 BackgroundScheduler 在 debug=True 时会被 reloader 启动两次，导致调度器重复运行。main.py 已固定 debug=False。

Q：手动触发任务时提示"任务正在执行中"怎么办？

A：同一任务设置了 max_instances=1，如果上次还没跑完，手动触发会被拒绝。请等待上次执行完成，或查看日志确认进度。

Q：Windows 下并行执行有问题吗？

A：Windows 使用 spawn 模式启动子进程，功能正常但启动开销比 Linux fork 大。如果账户数很少（<4），并行收益不明显。

Q：日志在哪里看？

A：任务日志存储在 data/simulation_results/task_logs/<task_id>.log，可以通过 Web 界面的"日志"按钮实时查看。

Q：数据存储格式变更后旧数据怎么办？

A：最简单的方式是让所有账户重跑一次，新文件会自动生成。模拟账户路径为 data/simulation_results/accounts/<account_id>/，实盘账户路径为 data/live/accounts/<account_id>/。
